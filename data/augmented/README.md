# augmented/ — Immagini aumentate (generate, non versionate)

Questa cartella è **vuota di proposito**. Qui il pipeline scrive le immagini
aumentate (rotazione, luminosità, occlusione) descritte nel Workstream A del
progetto, per simulare condizioni di campo.

- Le immagini si **generano** eseguendo il notebook di augmentation: non si
  caricano a mano e non si versionano su git (sono rigenerabili).
- Se la cartella ti appare vuota, è normale: significa che il pipeline non è
  ancora stato eseguito.

> Questo README sostituisce il vecchio `.gitkeep`: serve solo a mantenere la
> cartella nel repo e a spiegare, in modo leggibile, cosa ci va dentro.
